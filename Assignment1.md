URL Entry: We type the website address (URL) into the browser.
DNS Lookup: The browser finds the IP address of the website using DNS.
Connection Establishment: The browser connects to the web server using TCP and, for HTTPS, establishes a secure TLS connection.
HTTP Request: The browser sends an HTTP request to the server to get the webpage.
Server Response: The server processes the request and sends back the required files, such as HTML, CSS, and JavaScript.
Rendering: The browser reads these files, creates the webpage layout, applies styles, and runs JavaScript.
Page Display: Finally, the browser displays the webpage on the screen.
